OpenLine · built on CALL-E

Resumes in. Screened candidates out.
Humans decide everything in between.

📄Recruiter uploads resumes

Creates the job, drops in the PDFs. Originals are kept, so anything can be double-checked later.

Human

🤖AI reads & scores each one

Builds a profile from the resume and scores fit against the job description — with a note explaining why.

OpenAI

✅Shortlist forms

High scores go on automatically. The recruiter can add or remove anyone — the score is shown so it can be argued with.

Human decides

👁️Recruiter approves the script

Every candidate gets tailored questions. The recruiter reads the exact words — and can edit them — before anything is spoken.

Human approves

☎️CALL-E makes the calls

All of them, in parallel. It says it's an AI, asks if now is a good time, and ends the call politely if the answer is no.

CALL-E

📋Answers come back

Notice period, interest, availability — each answer paired with the candidate's own words from the transcript.

On the record

🤝Recruiter decides

Reviews, compares, schedules the strong ones. Anything unclear is flagged for a person. No machine ever rejects anyone.

Human decides
🛡️
One check runs the whole way through

Every question is screened against a list of things that can't lawfully be asked in hiring — age, religion, family plans, current salary, and so on. It runs when the script is written, again if a human edits it, and once more at the moment of dialing. A script that fails is blocked and shown with the reason, not quietly skipped.
